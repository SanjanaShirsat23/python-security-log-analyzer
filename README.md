# Python Security Log Analyzer

Python-based security log analyzer for identifying failed login attempts and suspicious authentication activity.

## Project Overview

This project uses Python to analyze authentication logs and identify potentially suspicious login activity.

The analyzer will examine failed login attempts, repeated failures by users, suspicious IP addresses, and authentication patterns that may require further investigation.

## Tools

- Python
- CSV
- GitHub

## Dataset

The project uses `login_events.csv`, a sample authentication log dataset.

## Project Status

Currently developing the log analysis and security detection functionality.
